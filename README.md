# Furniro E-Commerce Website

A pixel-perfect, fully responsive e-commerce web application built with **React JS** and **Tailwind CSS**, converted from a Figma design.

## Tech Stack & Tools

To ensure high performance, clean styles, and modern development standards, the following technologies were used:

![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)
![Vite](https://img.shields.io/badge/vite-%23646CFF.svg?style=for-the-badge&logo=vite&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/tailwindcss-%2338B2AC.svg?style=for-the-badge&logo=tailwind-css&logoColor=white)
![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=for-the-badge&logo=javascript&logoColor=black)

- **Frontend Library:** React.js (Functional Components & Hooks)
- **Build Tool:** Vite (For lightning-fast bundling and HMR)
- **Styling:** Tailwind CSS (For utility-first components and rapid responsive design)
- **Routing:** React Router DOM (For smooth page transitions)

  ---

## Features

- **Figma to React Conversion:** 100% pixel-perfect UI matching the original design closely.
- **Fully Responsive:** Smoothly adapts across Mobile, Tablet, and Desktop screens.
- **Dynamic Routing:** Seamless multi-page navigation using React Router.
- **Modern E-commerce UI:** Sleek product listings, functional navigation bars, and structural layouts ready for state management integration.

## Getting Started & Installation

Follow these quick steps to run the Furniro project on your local machine.

## Prerequisites
Make sure you have **Node.js** installed on your computer.
- [Download Node.js](https://nodejs.org/)

## Installation Steps

1. **Clone the repository:**
 ```bash
   git clone https://github.com/Erandi-Hans/furniro-ecommerce-react.git
   ```
   
3. **Navigate into the project directory:**
  ```bash
  cd furniro-ecommerce-react
  ```

3 .**Install the dependencies:**
  ```bash
  npm install
  ```


4. **Start the development server:**
  ```bash
  npm run dev
  ```

Open http://localhost:5173 (or the port specified in your terminal) in your browser to view the application!
